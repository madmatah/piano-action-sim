# Vocabulary: open questions

The French–English mapping lives in one place,
[A3 > Bilingual glossary FR ↔ EN (+ DE) and code identifiers](research/A3-nomenclature-and-regulation.md#bilingual-glossary-fr--en--de-and-code-identifiers). This file holds only what is
still open in it, each question written so that it can be answered without opening
anything else: the options, what each means, and what the answer changes. An answer
goes into [A3 > Bilingual glossary FR ↔ EN (+ DE) and code identifiers](research/A3-nomenclature-and-regulation.md#bilingual-glossary-fr--en--de-and-code-identifiers), and its question leaves this file.

This file is deliberately bilingual: the French terms are the subject matter. No
source is cited for a term; the trade's vocabulary belongs to the trade.

## Open questions

None at present. The glossary's terms that no French source attests are put to
the owner one at a time, each with what the sources say, and added here while one
waits for his answer.
